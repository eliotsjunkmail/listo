# Holdings

Shows the dollar value of a stock position as a progress bar toward a dollar target.

Defaults:

- Symbol: **SNAP**
- Shares: **130,000**
- Target: **$2,000,000**

Value = current price × shares. Symbol, share count, and target are editable.

## Open

https://eliotsjunkmail.github.io/listo/?v=7

Or locally:

```bash
npx --yes serve .
```
